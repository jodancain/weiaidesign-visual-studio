# Image Studio 2.0 implementation contract

Shared workspace, bounded owners. Backend agent: domain.mjs/store.mjs/router.mjs + their tests. Processing agent: processors.mjs/providers.mjs/restore.mjs/vision-worker + processor tests. Frontend agent: app/image2, components/image2, lib/image2 + UI unit tests. Root: package/lock, server.mjs, jobs.mjs, agent.mjs, exports.mjs, BFF, deployment/docs and integration tests. Do not edit another owner's files without coordination.

## Public model
Document: {id,name,schemaVersion:2,revision,width,height,layers:Layer[],assetIds:string[],createdAt,updatedAt, parentDocumentId?,baseRevision?,metadata?}
Layer: {id,type:'raster'|'text'|'vector'|'group'|'mask',name,x,y,width,height,rotation:degrees,opacity:0..1,visible:boolean,locked:boolean,z:number,parentId?,assetId?,maskAssetId?,sourceAssetId?,sourceRect?,text?,fontAssetId?,fontFamily?,fontSize?,fontWeight?,fill?,stroke?,strokeWidth?,tracking?,lineHeight?,editability?:'pixels'|'text'|'path',metadata?}
Document commands: {type:'layer.add',layer}, {type:'layer.update',layerId,patch}, {type:'layer.remove',layerId}, {type:'layer.reorder',layerIds}, {type:'document.update',patch:{name?,width?,height?,metadata?}}. Metadata is a validated replacement record; preserve other keys when updating one flag. Branch acceptance merges authored metadata keys with per-key conflict checks and excludes branch runId/candidateJobId bookkeeping. All geometry in document pixels; server is canonical. Masks are source pixel RGBA/gray with white editable/protected. Text sourcePatch asset may remain until fontConfirmed metadata.
Asset: {id,documentId,name,mime,hash,bytes,width?,height?,createdAt,metadata?,inputs?:[{role,assetId,hash}]}. Exact immutable bytes. Tenant owner authorization mandatory even for branches.
Job: {id,documentId,kind,state:'queued'|'running'|'complete'|'failed'|'uncertain'|'cancelled'|'awaiting_user',progress,stage,createdAt,updatedAt,output?,error?,retryable?}. private input/receipt/checkpoints never served wholesale.
Operation request: {documentId,baseRevision,operation,params?:{},inputs?:[{role,assetId}],targetLayerId?,idempotencyKey,mode?:'apply'|'candidate'}.
Run: {id,documentId,branchDocumentId,state,jobId?,message,output?,...}; conversation message persists references via assetId/layerId/revision, no ordinal fallback.

## HTTP
Full prefix /api/v3/image2. Internal Bearer required (server config token) plus x-studio-visitor-id UUID. Health /health no private state. Responses {data:T}; errors {detail,code}. No new public host port.
GET capabilities; GET/POST documents; GET documents/:id; POST documents/:id/commands {baseRevision,commandId,commands}; GET documents/:id/revisions; POST documents/:id/history {baseRevision,commandId,direction:'undo'|'redo'}.
POST assets {documentId,name,mime,data:base64,metadata?}; GET assets/:id/content; GET documents/:id/assets.
POST operations -> {job}; GET jobs/:id; POST jobs/:id/cancel; POST jobs/:id/retry {idempotencyKey}.
GET documents/:id/jobs; POST documents/:id/accept {branchDocumentId,baseRevision,commandId}; GET documents/:id/branches.
Accepted branch status is stored atomically in a server acceptance ledger, surfaced as metadata.acceptedAt/acceptedRevision/acceptedIntoDocumentId; pending branch lists exclude consumed candidates and a fresh repeated accept cannot overwrite later edits or add history.
GET/POST conversations {documentId}; GET conversations/:id/messages; POST conversations/:id/messages {text,references?,model?,idempotencyKey} -> {run,job}; GET runs/:id; GET documents/:id/runs. Optional model must match capabilities.agent.models (configured upstream allowlist); otherwise 422 agent_model_unavailable, with no run/job/message committed. First requested model and conversation message IDs are frozen before execution; duplicate accepted submissions keep their original model even after configuration changes.
POST imports/legacy {snapshot,name,width,height,assets:[uploaded asset mappings]} (no arbitrary URL fetching). POST imports/project {data:base64 ZIP}; POST exports {documentId,format:'project'|'svg'|'pdf'|'png',idempotencyKey,baseRevision,layerIds?:string[],bounds?:{x:number,y:number,width:integer,height:integer}} -> {job}. Exports execute same runner. Scoped SVG/PNG/PDF include selected group descendants and necessary transform ancestors, exclude unrelated siblings, and translate the requested infinite-canvas bounds (negative x/y allowed) to output origin. Width/height are positive actual pixel dimensions (up to 32768 each and 100M pixels). Project packages always retain the complete document/history and ignore view scope. Scope is frozen in the job and does not edit the document.
Restore via operation restore_layers; capabilities is honest to configured/runtime availability.

Operations resize,crop,pad,rotate,flip,recolor,erase,color_key,trace,matting,segment,super_resolution,restore_layers,generate,inpaint,export. Root handles export through exports.mjs rather than processors.
Input assetId from inputs role='base', else target layer assetId. Pixel source uses same-size edit/protect masks; protect wins and feather inward. Output saveAsset checkpoint then commands replacement/add actual asset ID.
Generation/restore defaults candidate. Branch runs explicitly apply all operations to branch. Source logo/font/vector assets preserved.
Providers module exposes capability assessment, generation/reference edits with receipt checkpoints, Comfy submit/poll/download persisting prompt_id, and OCR worker HTTP. No live generation in tests. Unknown acceptance throws with uncertain=true, no automatic charged resubmission. ML unavailable must not fall back generation.
Restore visible pixel coverage, original RGBA recompose equality, residual/background/masks and unknown font metadata; use exact pixel ownership rather than lossful reinterpretation.

## Root integration
Standalone MJS Node22 package (not Next TS scanning). Dependencies sharp, imagetracerjs, @resvg/resvg-js, fontkit, pdfkit, fflate, fast-xml-parser, css-tree. Frontend shares lib/image2/types.ts manually aligned by tests. The pure `svg-normalize.mjs` module is deliberately shared with the frontend; it has no Node, DOM, database or provider dependencies. Other service modules remain server-only.
Image2 Node internal port 18088, OCR port 8080 internal only, named volume /data/image2, read-only model volume. BFF IMAGE2_API_URL selects origin only and IMAGE2_API_TOKEN; missing ->503. Stable visitor secret bootstrap first.
Agent max6 rounds, persistent own branch, operations via registry. New typed scope validations; stopping/unknown receipts remain durable. Fake injected provider only in tests.
Agent references retain explicit per-message numbering, immutable asset/layer/revision IDs and normalized PNG vision previews. Preview source hash/encoding plan and content-hash blobs are durable before charged requests; no arbitrary URL fetching. Preview limits: 16 unique images, maximum edge 1536, 2 MiB each and 12 MiB total. Unpreviewed older/excess references retain labels and explicit omission reasons. Edit/protect/source metadata IDs remain in the authoritative branch projection. Inline Agent exports default to actual infinite-canvas content bounds, with optional layerIds/bounds; source revision and scope are frozen.
Native frame group metadata.frameClip=true clips descendants to its local (0,0,width,height) rectangle in SVG/PNG/PDF; group transforms and opacity retain their existing semantics.

## Shared SVG appearance and identity

Normalize immutable SVG source with its own viewport/viewBox and known intrinsic dimensions; canvas display width/height are a separate transform. Normalization keeps canonical drawing IDs and legacy aliases, namespaces DOM/resource IDs per instance, preserves safe embedded raster/font resources and CSS selectors, and rejects active or external resources. Resource geometry in defs/mask/clip/pattern/symbol is excluded from drawing paint controls. A SVG that only contains an embedded image is not advertised as directly paint-editable.

Canvas, pixel operations and exports must apply the same current `fill/pathStyles`. PNG uses an internal compiled SVG rendering proxy to resolve source CSS, root transparency and registered fonts before document compositing. The proxy avoids resvg's nested-root transparency duplication without resampling the source. SVG keeps the source paths; PDF may preserve appearance through a raster fallback where its converter cannot represent the source effects. PDF always contains actual PDF bytes.

Explicit `overflow=visible` or corresponding SVG CSS declarations currently fail with `422 SVG_OVERFLOW_UNSUPPORTED` and a correction message rather than silently dropping geometry outside the source viewport. Unknown system fonts are not guaranteed; use an actual registered font. Generated native-canvas SVG may use the existing local bitmap appearance projection for `422 SVG_*` responses. User-uploaded SVG and authentication/network/service failures do not use that fallback, and no fallback invokes a model.

Explicit `inputs.base` has priority. A different historical base does not inherit the current layer's paint, default mask or visibility baseline; an explicit `active_mask` applies to that selected base. The current source uses its full styled appearance when retaining a hidden-pixel baseline. Selecting historical styles for the same immutable asset ID requires a revision/snapshot contract; asset ID alone does not identify paint state.
