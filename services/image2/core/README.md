# Shared v3 software renderer

`render-graph.mjs`, `matrix.mjs`, `paints.mjs` and `render-software.mjs` contain no Node, DOM, database or provider access. They run with CanvasKit **0.42.0 software surfaces** in a browser Worker or a Node Worker. PathKit 1.0.0 is pinned for the subsequent path editing work; this renderer does not claim to implement Boolean editing.

The authoritative input is a validated v3 document. Matrices use `[a,b,c,d,e,f]`; `localBounds` is `{x,y,width,height}`. Parent matrices multiply once. `sourceRect` describes extraction provenance and never crops the current raster again. `prepareRenderGraph` obtains resources through an injected owner-checked resolver and rejects unregistered required features. Prepared raster resources are RGBA8 **straight alpha, sRGB**, while text and structured vectors are authored path lists. The Node adapter derives text paths from the actual registered font bytes and produces a deterministic SVG appearance proxy through the existing sanitized SVG pipeline. Raw SVG bytes and their source identities remain immutable.

`prepareRenderGraph(document,resolver,{layerIds?,bounds?,maxResourcePixels?})` produces a transferable graph. `renderSoftware(CanvasKit,graph,{bounds?,pixelScale?,background?,maxPixels?,maxWasmBytes?,cancelled?})` produces RGBA bytes and the document-space origin. Node `renderNode` additionally encodes PNG and computes an appearance cache key. Its default CPU frame runs in a terminable worker; `engine`/`useWorker:false` are explicit in-process adapters for offline checks. Resolving an individual content resource requires an authored layer, mask or saved selection reference; an explicit `layerId` cannot select a different layer's appearance.

Implemented rendering includes eight blend modes, isolated groups, effect-free full-opacity pass-through groups, alpha/luminance masks with inversion/density/feather, clipping to lower siblings, ordered color matrices, one Gaussian blur, full affine transforms, actual legacy-lines text and structured paths with evenodd holes. Guides and saved selections are editor state and do not print. Default measured bounds use authoritative content bounds, conservatively expand blur by three sigma, and retain negative origins. Explicit output bounds define clipping and remain preferred for full-document, artboard and viewport frames.

Unsupported authored features fail explicitly: adjustment layers, unknown effect/shader, tiles, perspective/warp, nonempty structured resources, per-path opacity and non-left text layout. Complex SVG is an appearance proxy, not a complete SVG interpreter. SVG text requires explicit actual fonts; unknown original text continues to display its original pixel patch and does not treat `desiredText` metadata as a visible edit. No model call occurs in this path.

Resource pixels, output pixels, estimated native memory, actual WASM heap and worker time are bounded. Shared pixels reuse native images and transfer only once; cancellation terminates a Node frame and does not detach the caller's reusable graph. Limits return an explicit error rather than silently reducing output resolution. Heavy document performance and browser pixel parity must be measured separately from the deterministic service tests.
