## 关键决定

文档是权威，画布/聊天/历史/下载引用同一个最终版本。资产只有新建，没有原图覆写。版本命令、处理任务和 Agent 工具位置分别幂等；响应丢失查询/重用原回执。不可确认收费提交不会自动补跑。

已有海报的文字在字体未知时仍显示原裁片。识别文本修改另存 desiredText，不冒充画面已改。字体确认要求实际字体文件包含所需 glyph，清底后背景从文字层分离。原像素、字体、SVG、遮罩和来源依赖进入原生工程包。

自动还原生成的是可修正的图层草稿。全可见像素有归属、首次重合成相同，与“字体已经识别”“隐藏背景已经恢复”“原 Logo 已变真实路径”分别验收。转换未知内容必须由用户明确选择和接受，失败不转整图生成。

按钮明确处理时不调用聊天模型；Agent 有语义请求时调用同一注册表。CPU 插值放大、专用细节超分和 AI 高清重绘分开。ArtCraft 仅作为模块拆分/工具执行架构参考，本版没有接入它的早期引擎，也没有新增 SAM3 或生成式分层模型。

## 实际限制

保真分层不猜测遮挡后的内容，未知区以 metadata 标记；移动后需按明确范围修补。字体拟合/识别置信度提供候选，不提供不存在的原始字体历史。字体清底不是任意复杂背景的自动保证。

传统修补采用局部像素算法，不能替代复杂自然内容生成。保细节描摹需要完整源图，小点/细孔测试通过不代表每张客户网点图均已人工验收。没有从用户截图逆向制造缺失原始素材。

组合透明度的 tldraw 预览不支持隔离混合；UI 禁止编辑这种属性和直接拆开非 1 透明度组，PDF 必要时保留位图组。其他可编辑文字/Logo 路径与原生树仍保留。SVG/PDF 允许包含位图裁片，没有 PSD/Adobe Illustrator 原生 `.ai` 承诺。

一次真实合成 OCR 样本、真实浏览器 CPU 操作和隔离协议测试，不代表生产环境的中文识别准确率、真实 GPU 清晰度或付费供应商性能。验收数据应按素材/处理器/模型记录，现阶段不宣称节省比例。
