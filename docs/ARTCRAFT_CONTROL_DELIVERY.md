## 已实现

- 保留原首页画布、顶部栏、底部工具栏和聊天区；在原元素弹窗加入调色／滤镜折叠区，在原矢量弹窗增加原色网点模式。
- 算法调色：亮度、对比度、曝光、饱和度、色相、伽马、灰度、反相、阈值、色阶。滤镜：高斯模糊、锐化、中值降噪。操作保留透明度，遵守修改／保护遮罩，可通过原版本窗口撤销。
- 原色描摹生成真正 SVG 路径，保留原色、孔洞、网点和像素边界；不默认超分、不生成平涂图、不删小区域。黑白和彩色近似模式仍可显式选择。
- 原 Agent 协议接通精确工程：14 项 CPU 操作、17 类文档命令，实际内容读写、文字／SVG／字体、变换、蒙版、选区、画板、参考线及导出通过同一受限工具入口执行。保持最多六轮工具循环、持久分支与最终候选接受。
- Agent 读取真实文字／路径内容和实际预览，未知字体保留原裁片；锁定层保护覆盖父组、剪贴基底及相关子树，未锁的无关兄弟仍可修改。
- 修复取消后继续执行模型回执工具、低 alpha 滤镜偏色、旧元素预览及后续遮罩使用旧资产的问题。迁移不再把 legacyRecord 内的 tldraw 旧编号误当服务资产；完整原快照继续保留。
- 对严格验证为整数矩形像素边界的 crispEdges SVG，服务和浏览器共享最近邻采样，避免缩小时二次插值损伤网点。采样语义与版本参与缓存，普通／混合SVG维持原规则。
- SVG 连续改色／描边使用串行字段增量，保留源SVG及字体身份；保留位图外观的SVG明确拒绝尚不能准确呈现的改色，Agent也不能借内容分步提交绕过。原弹窗新增精确HEX色值输入；未改值失焦不重复提交。
- 修复升级副本刷新后旧v2矢量对象重复导入：只去重已确认同源且唯一对应的旧显示对象，真实草稿保留为冲突；源工程草稿有独立恢复槽，旧回执不能删除新草稿。
- 候选采用真实 PNG，卡片与版本窗口共用版本检查；接受前重新读分支，服务端事务再次核对冻结的 branchRevision。没有匹配预览不能接受，空候选也输出透明 PNG；丢响应先恢复原幂等回执。
