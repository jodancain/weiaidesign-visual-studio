# 图片 2.0：原界面功能接入

用户工作台仍是 `/`。保留原 tldraw 无限画布、顶部项目栏、底部工具坞、右侧聊天、配色和布局；新增功能只出现在原按钮打开的弹窗、菜单和结果卡片内。`/image2` 是内部验收入口，不替换首页。

## 入口与处理路径

| 原入口 | 2.0 行为 |
| --- | --- |
| 元素 | 有明确范围时直接换色或擦除，并保留对象原位置、显示尺寸与旋转；真实文字／SVG 直接更新图层属性。描述性对象但没有范围时要求选择范围，不忽略对象描述而处理整图。 |
| 消除 / Quick Edit | 原图像素遮罩；编辑与保护独立，保护优先。透明擦除、传统修补、换色、填色使用 CPU；用户明确选择补画才生成候选。 |
| 矢量 | 保网点／线稿、彩色描摹，直接处理原图，不先生成平涂图。SVG 保留路径身份。 |
| 高清 | 尺寸放大（插值）、细节超分（Real-ESRGAN）和 AI 高清重绘独立。实际字体和矢量不发送整图超分。 |
| 改字 | 已确认文字直接改内容／颜色／字号。扁平图先指定像素范围与实际字体；简单背景 CPU 清底。复杂背景保留原字裁片待修补，不能用改识别元数据冒充画面已改。 |
| 图层 | 同风格弹窗管理文字、SVG、位图、组与辅助遮罩；锁定、显隐、层序、路径样式、实际字体及代码模板。 |
| 版本 | 持久版本、候选预览与接受、后台任务状态、撤销／重做、工程包导入。进行中候选不能接受。 |
| 原导出菜单 | 原选区优先、否则全页。后端导出实际 PNG／SVG／PDF；工程 ZIP 保留完整历史与素材，PDF 不伪装成 `.ai`。 |
| 原聊天 | 保存消息、稳定有序参考、后台最多六轮工具调用、任务分支。关闭网页不会取消服务器任务；接受后才写主工程。 |

## 原画布适配

`lib/image2/useLegacyImage2.ts` 负责原项目与服务端文档的映射，`legacy-projection.ts` 保留原 shape ID、无限画布坐标、分组及实际本地字体。

- 旧画布通过原风格弹窗**显式导入**，上传原素材并保留旧快照与原生对象记录，全部确认后才标记迁移完成。缺失素材保留说明，不重新生成。
- 普通原文字绑定四套真实 WOFF2 字体；混合富文本格式保留原生编辑与像素／SVG 投影，不静默抹掉加粗、斜体、换行或对齐。
- 生成或分层的结果先存在持久分支。接受是有服务端账本的幂等操作；已接受分支不再显示为待接受候选。
- 服务器投影使用 remote store changes，不制造用户编辑历史。原快捷键和右键撤销接入服务端版本。
- 原生本地编辑立即捕获到独立 IndexedDB 草稿库；并发上传期间新编辑继续保存。工程切换后旧异步响应不能删除或改写新工程画布。
- 命令、处理任务、聊天、接受和撤销使用冻结的版本与身份。丢回执先恢复原请求；收费提交未知标为 `uncertain`，不自动重投。
- 服务器版本冲突保留本地草稿；版本弹窗提供“另存本地草稿”和“采用服务器版本”，没有自动覆盖。
- 同素材的多个图层仍有独立身份。弹窗捕获目标图层，历史素材参考按不可变 asset ID 解析，不偷偷换为新版素材。

## 部署与验收

服务部署沿用 [IMAGE2_DEPLOYMENT.md](IMAGE2_DEPLOYMENT.md)。首页的图片处理通过 `/api/v3/image2/*` 访问独立服务；缺地址／令牌时明确不可用，不回退旧生成接口。OCR、Comfy、生成和 Agent 模型需要对应配置。生产部署和付费样例按明确授权执行。

```sh
npm run typecheck
npm run test:image2:client
npm run test:image2
npm run test:image2:original-ui
npm run test:image2:original-recovery
npm run test:image2:original-extended
npm run build
```

原首页浏览器矩阵需要独立 CPU 测试服务（`tests/image2-cpu-server.mjs`）和测试 Next BFF。模型配置置空且模型 fetch 被拒绝，审计区分公开 tldraw 静态资源与供应商请求。测试检查真实像素、尺寸、字体、路径、文件格式、保护区、候选与刷新；不能用 `/image2` 的测试结果替代原首页验收。

证据放在仓库外 `../output/image2-original-ui-20261012/`，包含升级前布局基线、原入口截图、矩阵、真实下载和提供商审计。实际生产模型效果、Linux Docker 镜像、用户原图与生产切换不属于本次本机 CPU 通过证据。

2026-10-12 本地验收：原首页最新逐项结果 22/22，恢复矩阵 10/10；8 个主布局区域的位置与尺寸差值为 0 px。早期完整首页运行为 21/22，四字体首次遇到临时 BFF 502，独立复测 1/1 通过；最终修复后两次完整重跑均 22/22 通过（约 2.2／1.9 分钟，四字体 46／33 秒）。原失败证据保留，502 根因未确认。BFF 仅对 GET/HEAD 的连接断开重试一次，不对 HTTP 错误、超时或提交请求重试。服务 141/141、客户端 34/34、Web 93/93、Python 6/6；类型检查、生产构建通过，ESLint 0 错误及 4 个既有提示。

四个原字体按钮已绑定完整官方字库（总计 35.69 MiB），字体字节、来源、许可及哈希见 `public/fonts/manifest.json`。首次下载与上传比旧残缺子集更大，URL 带字库版本；每个工程复用已上传字体资产。浏览器验收的生成、聊天、视觉模型调用全部为 0。后台 Agent 的收费运输与 GPU 模型验证采用测试适配器，不代表真实模型质量验收。

## 继续实测与几何约定

2026-10-12 继续从原上传按钮的文件选择器实测，扩展矩阵 6/6 通过。确认并修复裁切、填边和像素旋转把显示尺寸缩成输出像素尺寸的问题。操作按原图像素与画布显示的比例计算；裁切／填边通过当前图层角度补偿原点，保留原可见内容的世界位置；90°／270° 像素旋转交换缩放比例并保留原中心和父组。扁平图改字的临时图层采用原完整画布范围，裁切只补偿一次文字位置。

非等比拉伸图层的任意角度像素旋转需要剪切变换，当前图层模型不能无损表示；服务明确拒绝，保持原资产与工程不变。可以使用画布角度旋转、恢复等比尺寸或采用 90° 的倍数。等比图层的任意角度像素旋转仍可执行。

新增原右键副本、组显隐／锁定／历史、混合中文／SVG／位图导出、真实 PDF 渲染及工程回迁检查。手工浏览器实测另包含旋转图层的重叠修改／保护、原键盘撤销重做、单一路径改色和真实中文编辑；保护区 13,542 像素及修改范围外 337,742 像素的 RGBA 差异为 0，实际 PNG／PDF 全页尺寸均为 807×427。

手工保网点测试还发现透明像素参与 RGBA 聚类，使原不透明深色网点变为半透明蓝灰（180 个中心均为 `[36,86,110,172]`）。黑白线稿现按亮度二值化，采用固定黑／白／透明调色板，禁止量化平均、模糊、描边和小路径删除。整数像素边界生成真实 SVG `clipPath`，避免描摹曲线越过透明范围；不嵌入位图。最终原首页实际处理的 180 个中心均为 `[0,0,0,255]`，26,655 个原透明像素无漏色，原资产字节、画布位置／尺寸／旋转不变。彩色素材使用独立彩色描摹；模式连续切换时清除旧黑白阈值元数据。描摹仍是路径近似，不能承诺所有抗锯齿边缘逐像素一致。

几何修复后原首页完整重跑 22/22、恢复矩阵 10/10；最终描摹修复后对应原按钮用例再通过 1/1。最终服务 150/150（处理器 45/45）、客户端 34/34，typecheck、构建通过；本轮指定文件 ESLint 0 错误、1 个既有导航提示。浏览器产品的生成／聊天／视觉调用均为 0。后台进度使用中性的“正在处理后台任务”，不把 CPU 算法称为 Agent 执行。

新增证据分别在 `../output/image2-original-extended-20261012/` 与 `../output/image2-original-manual-20261012/`。原首页与恢复测试支持 `IMAGE2_BROWSER_EVIDENCE_DIR` 指定独立输出目录，便于重跑而保留旧报告；原首页矩阵需要将已有 `baseline-layout.json` 复制到该目录。

本机没有 Playwright 捆绑 Chromium 时，运行浏览器矩阵需指定已安装 Chrome：`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`。启动器找不到可执行文件不代表产品用例失败；原日志保留，再使用指定浏览器执行。
